## מטרה

יומן אילוף גור — פרויקט אישי של אמיליה, לא מסלול תרגול מסורתי.
שלא כמו `add_sub_100`, אין כאן retrieval, mastery, או SRS. במקום:
- **תיעוד פקודות**: רשימה אישית של מה שמלמדת + מתי + הצלחה.
- **מעקב התקדמות**: דיוק לכל פקודה לאורך זמן.
- **תפוקה**: PDF בסוף שמסכם את המדריך שלה לאילוף.

זה אבולוציה של Emiva ממסלולי מיומנות לכלי פרודוקטיביות אישי.

### תוכן

**אין יצירת תוכן ב-Emiva — אמיליה היא היוצרת.** המבנה:

```json
{
  "puppyName": "...",
  "puppyBirthday": "YYYY-MM-DD",
  "trainingStartDate": "YYYY-MM-DD" | null,
  "commands": [
    {
      "id": "cmd-001",
      "hebrewName": "שב",
      "englishName": "sit",
      "addedAt": 1719000000000,
      "targetSessions": 30,
      "attempts": [
        { "at": 1719001000000, "success": true, "notes": "מהיר היום" },
        { "at": 1719087400000, "success": false, "notes": "לא הקשיב" }
      ]
    }
  ],
  "freeNotes": [
    { "at": 1719000000000, "text": "התחילה האימון היום. היה כיף." }
  ]
}
```

### קוד

- **`src/lib/types.ts`:** הוספת טיפוסים `PuppyJournal`, `PuppyCommand`,
  `PuppyAttempt`, `PuppyFreeNote`.
- **`src/lib/puppy-journal.ts`** (חדש, pure):
  - `loadJournal(profileId): PuppyJournal | null`
  - `saveJournal(profileId, j: PuppyJournal): void`
  - `addCommand(j, hebrewName, englishName, targetSessions): PuppyJournal`
  - `addAttempt(j, commandId, success: boolean, notes?: string): PuppyJournal`
  - `addNote(j, text: string): PuppyJournal`
  - `computeSuccessRate(cmd: PuppyCommand): number` — אחוז הצלחות.
  - `commandIsLearned(cmd): boolean` — לפי `attempts.length >= targetSessions && successRate >= 0.8`.
- **`src/lib/storage.ts`:** מפתחות `emiva.puppy_journal.v1.{profileId}`.
- **`src/app/journal/puppy/page.tsx`** (חדש):
  - **שלב התקנה** (אם אין יומן): "מה השם של הגור שלך?" → onboarding.
  - **שלב פעיל**:
    - כותרת: שם הגור + ימים מ-trainingStartDate.
    - רשימת פקודות: שם, אחוז הצלחה, badge "נלמדה" אם רלוונטי.
    - כפתור "הוסיפי פקודה" → טופס: שם בעברית, שם באנגלית, מספר סשנים יעד.
    - כפתור "תרגלנו עכשיו" עבור כל פקודה → תיעוד מהיר ✓/✗.
    - כפתור "כתבי הערה חופשית" → תיבת טקסט עם שמירה.
  - **כפתור PDF**: "ייצוא 'המדריך שלי לאילוף'" → jsPDF download.
- **דשבורד ההורה:** כרטיס חדש לאמיליה "פרויקט הגור": שם הגור, מספר
  פקודות, מספר נלמדו, כפתור "ראי יומן" (קריאה בלבד).
