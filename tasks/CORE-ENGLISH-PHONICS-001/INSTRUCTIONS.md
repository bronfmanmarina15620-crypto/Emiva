## בטווח

מיומנות חדשה `english_phonics`, 5 דרגות שמשקפות את סדר הרכישה:

| דרגה | מה | דוגמה |
|---|---|---|
| 1 | זיהוי אות — שם + צורה | שומעת /biː/ → בוחרת **B** |
| 2 | אות → צליל | רואה **m** → בוחרת את הצליל /m/ |
| 3 | צליל → אות | שומעת /s/ → בוחרת **s** |
| 4 | הברה (CVC) | שומעת /kæt/ → בוחרת **cat** |
| 5 | מילה קצרה — פענוח | רואה **sun** → בוחרת את התמונה/משמעות |

**קול:** הקראה דרך הדפדפן (Web Speech API) — בלי עלות, בלי אינטרנט,
בלי קבצי-שמע. כפתור 🔊 על כל פריט, ניתן ללחוץ שוב ושוב.

**נגישות:** אם הדפדפן לא תומך בהקראה — הפריט עדיין עובד ויזואלית,
ומוצגת הודעה עדינה. לא נופלים למסך שבור.
