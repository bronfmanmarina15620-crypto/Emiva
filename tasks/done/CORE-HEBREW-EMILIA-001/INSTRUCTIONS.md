### תוכן

**`src/content/hebrew/comprehension-emilia.json`** (חדש) — 60 פריטים:

- **D1 (12 פריטים, 6 מאמרים + 6 סיפורים) — בסיס למעבר אוולין→אמיליה.**
  טקסט 80-100 מילים. שאלות עובדתיות + 1 הסקה מקומית.
- **D2 (12 פריטים) — הקשר רחב יותר.**
  טקסט 100-130 מילים. שאלה אחת על מבנה הטקסט / רעיון מרכזי.
- **D3 (12 פריטים) — אוצר מילים בהקשר.**
  120-150 מילים. שאלה אחת חובה על משמעות מילה/ביטוי בהקשר.
- **D4 (12 פריטים) — הסקה רב-שלבית.**
  150-180 מילים. שתי השאלות דורשות חיבור בין מקטעים שונים בטקסט.
- **D5 (12 פריטים) — ניתוח דמות / טיעון.**
  180-200 מילים. עבור סיפורים: ניתוח מוטיב / קונפליקט. עבור מאמרים:
  הערכת טיעון / זיהוי הנחה.

לכל פריט:
```json
{
  "id": "hce-001",
  "skill": "hebrew_comprehension",
  "difficulty": 1,
  "source_type": "article" | "story",
  "topic": "nature" | "history" | "science" | "family" | "friendship" | "sports" | "art" | "social" | "personal",
  "text": "...",
  "questions": [
    { "question": "...", "options": ["...","...","...","..."], "correctIndex": 0|1|2|3, "explanation": "..." },
    { "question": "...", "options": [...], "correctIndex": ..., "explanation": "..." }
  ]
}
```

קונבנציית מזהים: `hce-NNN` (Hebrew Comp Emilia).

  - הוספה: `source_type: "article" | "story"` (אופציונלי כדי לא לשבור את הקיים).
  - הוספה: `topic: string` (אופציונלי).
  שאר השדות זהים.
- **`src/app/session/page.tsx`:**

    הפעיל. השינוי הזה דורש להעביר את `profile` למעלה במסלול
    bankForSkill (כיום הוא מקבל רק skill). תיקון פשוט: `bankForSkill(skill, profile)`.

  - בדיקה: routing אחרי `mult_2digit` graduation → `hebrew_comprehension`.
