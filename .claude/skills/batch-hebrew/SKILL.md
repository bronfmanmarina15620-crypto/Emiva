# הוספת batch — הבנת הנקרא לאמיליה

המשימה: `CORE-HEBREW-EMILIA-001`. היעד 60 פריטים, נבנים ב-batches של ~10.

## לפני שמתחילים — לבדוק מצב, לא לנחש

```bash
node -e "
const b=require('./src/content/hebrew/comprehension-emilia.json');
const items=Array.isArray(b)?b:(b.items||[]);
const byD={},byT={},topics=[];
items.forEach(i=>{byD[i.difficulty]=(byD[i.difficulty]||0)+1;byT[i.source_type]=(byT[i.source_type]||0)+1;topics.push(i.topic)});
console.log('סה\"כ:',items.length,'| אחרון:',items[items.length-1].id);
console.log('דרגה:',JSON.stringify(byD),'| סוג:',JSON.stringify(byT));
console.log('נושאים תפוסים:',topics.join(', '));
"
```

זה נותן: כמה יש, מה ה-id הבא, ואילו נושאים **אסור** לחזור עליהם.

## כללי ה-batch

| כלל | ערך |
|---|---|
| גודל | 10 פריטים (אלא אם מרינה ביקשה אחרת) |
| איזון סוג | 5 `article` + 5 `story` |
| איזון דרגה | 2 לכל דרגה (D1–D5) |
| נושאים | **חדשים בלבד** — אף אחד מהרשימה התפוסה |
| id | רציף: `hce-031`, `hce-032`, ... |

## אורך טקסט לפי דרגה

- **D1** — 80–100 מילים. שאלות עובדתיות + הסקה מקומית אחת.
- **D2** — 100–130 מילים. שאלה על מבנה או רעיון מרכזי.
- **D3** — 120–150 מילים. **חובה שאלת אוצר-מילים בהקשר.**
- **D4** — 140–180 מילים. הסקה רב-שלבית.
- **D5** — 150–200 מילים. ניתוח טיעון (מאמר) או ניתוח דמות (סיפור).

בכל טקסט: **לפחות 2 מילים מאתגרות** (רמת גיל 11+) כדי לדחוף אוצר מילים.

## מבנה פריט

כל פריט: טקסט + **2 שאלות אמריקאיות**, 4 אפשרויות לכל שאלה.
להעתיק את הסכימה המדויקת מפריט קיים בקובץ — לא להמציא שדות.

## כללים קשיחים

1. **תוכן מקורי בעברית.** לא לקחת ממקור חיצוני.
2. **בלי שמות הבנות בתוך הטקסטים.** כלל אבטחה — ראי §סטנדרטי אבטחה.
3. **טון growth-mindset** בכל טקסט שנוגע בהצלחה/כישלון —
   ראי [.claude/rules/pedagogy.md](../../rules/pedagogy.md).
4. **הסחות דעת סבירות.** 3 האפשרויות השגויות צריכות להיות מפתות
   למי שלא קרא בעיון — לא אבסורדיות.
